LexNote（通常版）静的サイト
========================================

ファイル
- index.html  : トップページ
- terms.html  : 全14条の利用規約・同意UI
- styles.css  : 共通スタイル（レスポンシブ対応）
- script.js   : モバイルナビゲーション・同意チェックの動作

公開方法
1. 4ファイルを同じディレクトリに配置します。
2. index.html を入口としてブラウザで開きます。
3. GitHub Pages等では、4ファイルをリポジトリ内の同じ階層にアップロードしてください。

すべてのページ・スタイル・スクリプト参照は相対パスです。
ビルド工程・外部ライブラリは不要です。

規約制定日・最終改定日：2026年11月1日（日曜日）
本サイトは講義・ゼミ発表用の架空サイトです。


トップページのノートイラストは、初回作成時の紙面型デザインを復元しています。画像ファイルに依存せず、HTML/CSSで表示します。

デザイン：山並みの装飾はHTML内に埋め込んだSVG、ノート・付箋・罫線等はCSSで描画しています。外部画像ファイルに依存しません。スマートフォン向けのレスポンシブ表示に対応しています。
