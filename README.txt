LexNote（通常版）静的サイト一式

ファイル
- index.html : トップページ
- terms.html : 全14条の利用規約ページ
- styles.css : 共通スタイル・レスポンシブスタイル
- script.js : モバイルナビゲーション・同意UI

利用方法
1. すべてのファイルを同じフォルダに配置してください。
2. index.html をブラウザで開くと閲覧できます。
3. GitHub Pagesでは、フォルダ内のファイルを同一ディレクトリに配置して公開してください。

CSS・JavaScript・ページ遷移は相対パスで指定しており、リポジトリのサブディレクトリ配下での公開に対応しています。
本サイトは講義・ゼミ発表用の架空サイトです。
