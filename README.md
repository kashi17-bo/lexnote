# LexNote（架空サービス）— GitHub Pages用サイト

ゼミ発表で定型約款制度を説明するための、架空の学習資料サービス「LexNote」の静的ウェブサイトです。

## ファイル構成

- `index.html`：トップページ
- `about.html`：サービス概要・取引設定
- `terms.html`：架空のサービス利用規約
- `style.css`：共通デザイン
- `assets/`：画像などの素材用フォルダ

## GitHub Pagesで公開する手順

1. GitHubにログインし、新しいリポジトリを作成します（例：`lexnote`）。
2. このフォルダ内のファイルをリポジトリの最上位にアップロードします。`index.html` が最上位にあることを確認してください。
3. リポジトリの **Settings → Pages** を開きます。
4. Build and deployment の Source で **Deploy from a branch** を選択します。
5. Branch を `main`、フォルダを `/(root)` にして Save を押します。
6. 数分後、同じ Pages 画面に公開URLが表示されます。
7. 公開URLの末尾を `terms.html` にすると利用規約ページ、`about.html` にするとサービス概要ページが開きます。

公開URLの例（実際のURLはリポジトリ名・アカウント名で変わります）：
`https://ユーザー名.github.io/リポジトリ名/`

## QRコードについて

公開URLが確定してから、そのURL（通常は `terms.html` へのURL）でQRコードを生成し、レジュメに貼り付けてください。公開前に生成した仮のQRコードは使用しないでください。

## アクセス範囲について

GitHub Pagesの通常の公開サイトは、URLを知っている人だけにアクセスを限定する機能ではありません。QRコードをゼミの参加者に配布することで実用上の閲覧先を限定することはできますが、URLが共有されれば他の人も閲覧できます。厳密なアクセス制限が必要な場合は、認証機能を備えた別の仕組みを検討してください。
