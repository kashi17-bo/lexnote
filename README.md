# LexNote（通常版）

講義・ゼミ発表用の架空オンライン学習ノート共有サービスの静的Webサイトです。

## ファイル構成

- `index.html` — トップページ
- `terms.html` — 全14条の利用規約・同意デモ
- `assets/style.css` — 共通スタイル・レスポンシブ対応
- `assets/main.js` — モバイルナビゲーション・同意チェック動作

## 表示方法

`index.html` をブラウザで開いてください。ビルドやサーバーは不要です。

## GitHub Pages

このフォルダ内のファイルをリポジトリの公開対象ディレクトリにアップロードしてください。CSS・JavaScript・ページ遷移は相対パスで指定しています。

本サイトは架空のデモであり、アカウント登録、決済、実際のサービス提供は行いません。
